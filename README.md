# สรุปเรื่องอุปกรณ์ภายนอกและระบบ I/O (External Devices & I/O System)

เนื้อหานี้สรุปจากหลักการทำงานเบื้องต้นของคอมพิวเตอร์เกี่ยวกับการเชื่อมต่อกับอุปกรณ์ภายนอกผ่านโมดูลควบคุม

---

## 1. นิยามของอุปกรณ์ภายนอก (Definition of External Devices)
**อุปกรณ์ภายนอก** หรือที่เรียกว่า **"Peripheral" (อุปกรณ์ต่อพ่วง)** คือเครื่องมือที่ใช้แลกเปลี่ยนข้อมูลระหว่างคอมพิวเตอร์กับสภาพแวดล้อมภายนอก โดยมีลักษณะการเชื่อมต่อดังนี้:
* ไม่เชื่อมต่อกับ CPU โดยตรง แต่เชื่อมต่อผ่าน **I/O Module**
* ใช้ Link ในการแลกเปลี่ยนสัญญาณ 3 ประเภท:
    1. **Control (สัญญาณควบคุม):** คำสั่งว่าให้ทำอะไร
    2. **Status (สัญญาณสถานะ):** บอกว่าอุปกรณ์พร้อมหรือไม่
    3. **Data (ข้อมูล):** ชุดบิตข้อมูลที่ต้องการรับ-ส่ง



---

## 2. การจำแนกประเภทอุปกรณ์ (Classification)
เราสามารถแบ่งอุปกรณ์ภายนอกตามลักษณะการใช้งานได้เป็น 3 กลุ่มหลัก:

| ประเภท | คำอธิบาย | ตัวอย่าง |
| :--- | :--- | :--- |
| **Human Readable** | สำหรับสื่อสารกับผู้ใช้งานมนุษย์ | จอภาพ (Monitor), เครื่องพิมพ์ (Printer), คีย์บอร์ด |
| **Machine Readable** | สำหรับสื่อสารกับอุปกรณ์หรือระบบคอมพิวเตอร์อื่น | ฮาร์ดดิสก์ (Disk Drive), เซนเซอร์ (Sensors), ตัวขับเร้า (Actuators) |
| **Communication** | สำหรับการติดต่อสื่อสารกับอุปกรณ์ทางไกล | โมเด็ม (Modem), การ์ดเครือข่าย (Network Interface) |

---

## 3. องค์ประกอบภายในของอุปกรณ์ภายนอก (Internal Structure)
เพื่อให้สามารถทำงานร่วมกับคอมพิวเตอร์ได้ อุปกรณ์ภายนอกมักมีโครงสร้างพื้นฐานดังนี้:

* **Control Logic:** ส่วนตรรกะที่คอยรับคำสั่งจาก I/O Module เพื่อควบคุมการทำงานของอุปกรณ์
* **Transducer (ตัวแปลงสัญญาณ):** ส่วนที่ทำหน้าที่แปลงพลังงาน เช่น แปลงจาก **พลังงานไฟฟ้า (Bits)** เป็น **รูปแบบอื่น** (แสง, เสียง, สนามแม่เหล็ก) และในทางกลับกัน
* **Buffer (ที่พักข้อมูล):** หน่วยความจำขนาดเล็กที่ใช้พักข้อมูลชั่วคราว เพื่อชดเชยความเร็วที่แตกต่างกันระหว่างอุปกรณ์และคอมพิวเตอร์



---

## 4. ตัวอย่างการทำงาน (Examples)

### Keyboard/Monitor (การโต้ตอบกับผู้ใช้)
* ใช้รหัสมาตรฐาน **IRA (International Reference Alphabet)** ขนาด 7 หรือ 8 บิต
* เมื่อกดปุ่มคีย์บอร์ด **Transducer** จะแปลงแรงกดเป็นรหัสบิตส่งไปยัง I/O Module
* เมื่อแสดงผล จอภาพจะรับรหัสบิตมาแปลงกลับเป็นจุดแสงบนหน้าจอ

### Disk Drive (การเก็บข้อมูล)
* มีวงจรควบคุมหัวอ่าน/เขียน
* **Transducer** ทำหน้าที่แปลงระหว่าง **สนามแม่เหล็ก** บนแผ่นดิสก์ให้กลายเป็น **ข้อมูลดิจิทัล (Bits)** ใน Buffer

---

## บทสรุป (Summary)
อุปกรณ์ภายนอกเป็นตัวกลางที่ทำให้คอมพิวเตอร์ไม่ใช่แค่กล่องประมวลผลที่ปิดตาย แต่สามารถรับข้อมูลและแสดงผลลัพธ์สู่โลกจริงได้ โดยหัวใจสำคัญคือการแปลงสัญญาณผ่าน **Transducer** และการบริหารจัดการคิวข้อมูลผ่าน **Buffer** ภายใต้การควบคุมของ **I/O Module**
